|                    | CAGR                           | IRR                       | XIRR                         |
| ------------------ | ------------------------------ | ------------------------- | ---------------------------- |
| **Applicable for** | Lumpsum                        | Fixed regular investments | Random deposits & withdrawal |
| **Used for**       | One time investments (lupsums) | SIPs with no lumpsum      | SIPs with lumpsums           |
| **Example**        | Investments in land            | Mutual fund               | Mutual fund / stocks         |
|                    |                                |                           |                              |
